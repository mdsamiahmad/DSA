<h2><a href="https://leetcode.com/problems/trapping-rain-water/">42. Trapping Rain Water</a></h2>
<h3>Hard</h3>
<hr>
<p>Given <code>n</code> non-negative integers representing an elevation map where the width of each bar is <code>1</code>, compute how much water it can trap after raining.</p>

<h3>Example 1:</h3>
<pre>
<b>Input:</b> height = [0,1,0,2,1,0,1,3,2,1,2,1]
<b>Output:</b> 6
<b>Explanation:</b> The above elevation map is represented by the array.
In this case, 6 units of rain water can be trapped.
</pre>

<h3>Example 2:</h3>
<pre>
<b>Input:</b> height = [4,2,0,3,2,5]
<b>Output:</b> 9
</pre>

<hr>
<h3>Constraints:</h3>
<ul>
  <li><code>n == height.length</code></li>
  <li><code>1 &lt;= n &lt;= 2 * 10<sup>4</sup></li>
  <li><code>0 &lt;= height[i] &lt;= 10<sup>5</sup></code></li>
</ul>
